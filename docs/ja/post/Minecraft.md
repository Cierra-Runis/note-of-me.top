# Minecraft

最近 Minecraft のサーバーをいじっていて、書きたいことができたので、ここにまとめて書いておく。

## Minecraft Java Edition

これは本当に僕に最も大きな影響を与えたゲームで、他に並ぶものはない。残念なことに、僕が初めてこのゲームに触れた時の記憶は全く残っていない。話したいことはたくさんある。

当時最も遊んだシングルプレイヤーのバージョンは `1.7.2` で、他には `1.6.4`、`1.7.10`、`1.8`、`1.10.2` といった印象に残るバージョンも、比較的少なめに遊んだ。サーバーについては、そのサーバーがどのバージョンを使っているかによった。

PC では「麦块我的世界盒子」という名前のソフトウェアを使っていた。当時の僕は Java を全く学んだことがなく、Minecraft が Java で書かれていることは知っていたが、Minecraft 自体は EXE プログラムのようにダブルクリックで起動できるものではなく、ランチャーから起動する必要があることを知らなかった。ランチャーというのも GUI を一枚かぶせて、起動パラメータを設定しやすくしたもので、最終的にはコマンドラインで起動するものだ —— そりゃそうだ、EXE は Windows システムの実行可能ファイルだし、Minecraft Java Edition は Windows だけをサポートしているわけではなく、macOS や Linux でも動く。~~本当に Linux でゲームをする人なんているのか？~~

今は [HMCL](https://github.com/HMCL-dev/HMCL) と [PCL2](https://github.com/Hex-Dragon/PCL2) という 2 つのランチャーが人気で、麦块と同じようなものだが、麦块にはフォーラムのような要素もあって、確か関連動画も見られたはずだ。

実際、Minecraft は有料ゲームだが、公式は海賊版に対して寛容な態度を取っており、取り締まりを行っていない。これが僕のようなゲームを買うお金のない子供たちがプレイできる理由だった。海賊版行為については、今後記事を書いて議論したいと思う。当時の僕は本当に正規版アカウントが欲しかった。なぜなら、海賊版アカウントにはスキンがなく、デフォルトは Steve だったし、一部のサーバーは「正規版認証」を有効にしていて、正規版アカウントを持つプレイヤーしか参加できなかったからだ。

当時の価格は 165 人民元で、僕にはそんな大金を手に入れることは絶対に不可能だったし、さらにネットショッピングもネックだった。中学 3 年生の後になってようやくネットショッピングができるようになった。そして 2022 年 5 月 13 日、Minecraft で Bedrock Edition を買うと Java Edition も付いてきて、しかも価格が非常にお得だったので、ようやく正規版を購入し、長年の付き合いへの感謝とした。

正規版アカウントを持っていない時は、スキンステーションでスキンを変更できた。今でも運営されている [LittleSkin](https://littleskin.cn) のようなものだ。具体的なスキンファイルは、[McBBS](https://www.mcbbs.co) や [我的世界中文下载站](http://www.minecraftxz.com) で好きなものを探すことができたし、もちろん自分で作ることもできた。僕自身は絵が描けないので、気に入ったスキンを見つけて、ちょっとだけ修正して、今まで使っているこのスキンができた。

[世界のトロッコから](https://ja.minecraft.wiki/w/%E3%83%81%E3%83%A5%E3%83%BC%E3%83%88%E3%83%AA%E3%82%A2%E3%83%AB:%E5%AE%9F%E7%B8%BE%E3%82%AC%E3%82%A4%E3%83%89#%E4%B8%96%E7%95%8C%E3%81%AE%E3%83%88%E3%83%AD%E3%83%83%E3%82%B3%E3%81%8B%E3%82%89) は Minecraft の [実績](https://ja.minecraft.wiki/w/%E5%AE%9F%E7%B8%BE_(%E6%9B%96%E6%98%A7%E3%81%95%E5%9B%9E%E9%81%BF)) の一つで、プレイヤーは「トロッコで旅をし、出発地点から少なくとも 500 メートル離れた位置まで移動する」ことが求められる。しかし、なぜか僕はこの実績を獲得できなかった —— そのために非常に長い線路を敷設したんだ、無限遠点に消えていくような —— 今思えば、クリエイティブモードでは実績が獲得できないのかもしれない。
