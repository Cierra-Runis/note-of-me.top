# 尾声

「我现在明白了，」我对 Moo 咳着说道。半死不活地挣扎出水面，我痛苦地爬上岸，趴在我忠实朋友的脚边。「我明白了一切，」我重复道，以此回应她那声心领神会的「终于明白了」的哞叫。我大口喘着气，步履蹒跚地走向她。

「一切都联系起来了，」我告诉她，我们俩走进树林。「当我在下面，淹没在深水中时，我一直在想一切是如何回到原点的，关于结局和开始，以及它们其实是一回事。」

这时我们已经走到了羊群吃草的地方。「大家集合，」我宣布道。「我有重要的事情要说。」当然，它们没听，但这能阻止我说话吗？

「继续前进，」我开始说道。「这是我在这里学到的第一课，现在它将是最后一课。」我停顿了一下，让我的话沉淀下来。「我必须接受这样一个事实：我正处于一次冒险的终点，也是另一次冒险的起点。我必须继续前进。我必须离开这个岛。」

在它们还没来得及说什么，还没来得及通过转身吃草来假装不在乎之前，我补充道，「不，不，听我说完。就像我说的，我现在明白了。事实上，我已经明白很久了。自从建完第二座房子后，这种感觉就一直折磨着我。这就是为什么从那以后我一直表现得这么疯狂。我不想承认这个可怕的事实。」

「是什么？」Moo 哞叫道。

「那就是，」我回答，「在如此努力地创造一个安全的空间来回答那些真正重大的问题之后，我意识到这些问题的答案无法在一个安全的空间里找到。」

我指向地平线。「它们在那未知的远方。」

「咩，」Rainy 问道，羊群都看着我。

「好问题。希望那里有更多的陆地，更多的人。希望我能找到回家的路。」

Moo 发出了一声轻柔、悲伤的「哞」。就在这时，我的眼泪流了下来。

「不，你是对的，」我哽咽着说。「『这里』也是我的家，我会把它的记忆珍藏在心里，因为即使我找不到我在寻找的答案，寻找本身才是真正重要的。」

这就是这个世界的终极教训。

「我为了一个目标如此努力地奋斗，却没有意识到目标就是奋斗本身。正是它让我变得更强壮、更聪明、更优秀。成长不来自舒适区，而来自离开舒适区。」

—

一周后，我打包好了长途航行所需的一切。食物、工具、指南针和一张尚未填写的地图。我确保花园打理得很好，房子也准备好迎接新的访客。

那个访客，正如你所知，就是你。希望你觉得我的房子舒适，如果你想建一个地下音乐工作室，我已经把那本书，连同所有其他手册，都留在了我的卧室里。你正在读的这本书是我找到的最后一本手册里的最后一项，由糖纸、Moo 已故伴侣的皮革，以及我很久以前杀死但没找到用途的鱿鱼墨水制成。想来也是。

这将是我走下山坡去我的船之前，在向我挚爱的朋友们道别之前写的最后的话。请善待它们。朋友让你保持理智。

我不知道地平线那边有什么在等着我，但现在我已经准备好迎接一个更大的世界。也许我会遇到我找到的那些书的作者。也许他们也像我一样是漂流者。也许他们故意留下那些书来帮助未来的旅行者踏上旅程，就像我为你留下这本书一样。

希望我学到的东西能帮助你找到你的路。最重要的是，希望你已经明白，在这个充满矿井和合成的世界里，你能合成的最重要的东西就是你自己。
