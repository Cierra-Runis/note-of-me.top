### Game Theory: What ARE Minecraft Creepers?!?

<iframe src="https://www.youtube.com/embed/wqKT5R2PXlw" allowfullscreen style="width:100%; aspect-ratio:16/9; border: none; border-radius: 1em; margin: 1em 0"/>

Game Theory 认为苦力怕是一种苔藓生物，类似地球上的某些苔藓。它们通过爆炸来传播孢子，从而繁殖后代。理由：

1. 苦力怕的颜色与苔藓相似，Notch 也解释苦力怕的材质和干叶子相似
2. 孢子会堆积大量的气压使其爆炸，嘶嘶声类似于气压释放
3. 闪电苦力怕和部分拥有优良电气特性的苔藓相似
4. 苦力怕攻击玩家的目的是在玩家的尸体上获取养分，即便没有死亡，也能进行传播

### Game Theory: The TRUTH About Minecraft's World

<iframe src="https://www.youtube.com/embed/QxckzCO7VI8" allowfullscreen style="width:100%; aspect-ratio:16/9; border: none; border-radius: 1em; margin: 1em 0"/>

Game Theory 认为 Minecraft 世界是静止不动的球形行星，日月以同一速度绕行星旋转。理由略。

这里举出个人观点：

1. 既然是球形，那么行星半径应该极其的大
2. 无法解释边远之地 —— 可以不引入该设定，因为太远了，所以没人知道这样
3. 星星的位置总是相对不变，可以佐证 Game Theory 的观点
4. 月亮的相位变化无法解释
