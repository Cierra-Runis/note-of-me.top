# 第二章　恐惧会淹没理智

利用我的新「超能力」，我敲掉了其余树木上的叶子方块。我不仅又得到了两个苹果，还对我的腰带和背包有了一个至关重要的发现。

这发生在得到第一个苹果之后，当时我正在敲打树叶。它没有掉落水果，而是掉落了一棵小树苗。「又罢工了？」我问着我那只冻僵的手，把这棵迷你树扔进了腰带里。几秒钟后，当我得到第二棵树苗时，我心不在焉地把它塞进了同一个口袋。就在那时，我意识到它们不仅缩小了，而且像扑克牌一样变平并堆叠在了一起。「好吧，」我笑着说，「这实际上可能很有用。」

这其实是轻描淡写了。当我把三棵树都剥光时，我设法在一个隔层里堆叠了十二棵压缩的树苗。而且，我要补充一点，重量为零！

看着背包里额外的口袋，我想，_我可以携带整整一个仓库的东西！这意味着……_

「这意味着，」我皱着眉头看着腰带说，心情像堆叠的树苗一样泄了气，「在找到值得携带的东西之前，你就像风力风扇一样有用。」

*肯定还有更多的苹果树，*我想，盯着悬崖上方。透过恐慌的双眼，它最初看起来像是一个不可逾越的障碍。现在，冷静、自信且吃饱喝足后，我可以看到它更像是一个陡峭的斜坡，而不是一面垂直的墙壁。

*谁知道那边还有什么，*我想，爬上方形的泥土立方体。如果我当时头脑清醒，而不是像个十足的笨蛋，我就不会把自己困在岛的这一边了。

事实上，也许这根本不是一个岛。也许这片海滩是一整块大陆的开始！别误会，我并没有放弃这一切只是一场梦的想法。但是，我内心深处还是忍不住希望翻过山顶能看到一个护林站，或者一个小镇，或者一个巨大的城市，或者……

并没有。

我站在平坦、绿色的山顶上，带着极度失望的心情凝视着这座无人岛的其余部分。

陆地像爪子一样伸展开来，两个树木繁茂的钳子几乎包围了一个圆形的浅泻湖。我无法判断这个岛有多大。那时，我还不太擅长用方块来测量。但它不可能太大，因为在午后的阳光下，我绝对可以看到它的尽头。随着橙色方块的下沉，我的心情也随之低落。

就像在水里一样，我以为我是独自一人。

就像在水里一样，我错了。

「哞。」这个声音吓了我一跳。

「什……？」我说，紧张地环顾四周。「谁……谁在那里？」

「哞，」声音再次传来，把我的目光引向山脚。那是一只动物，黑白相间，身体和周围环境一样呈长方形。

我顺着西坡往下走，那里比险峻的东坡更容易、更平缓，径直走向那个无所畏惧的生物。仔细观察，我发现它并不完全是黑白的。_灰色的角，耳朵里面是粉红色的，肚子下面有一个粉红色的浅袋子……_

「你一定是头牛，」我说，那声「哞」是我一整天听到的最美妙的声音。「你不知道见到你我有多高兴，」我叹了口气。「我是说，嘿，我知道这仍然只是一场梦什么的，但不再是——」这个词卡在我的喉咙里，刺痛了我的鼻子和眼睛——「独自一人，感觉真好。」

「咩，」牛回答道。

「等等，什么？」我问，走近了一步。「你是，比如说，双语者还是……」

「咩，」那只动物说，但不是我面前的那只。我抬头越过那头牛，看向声音的真正主人。它是长方形的——_废话_——但稍微矮一点，几乎全是黑色的。

在傍晚昏暗的光线下，我差点错过了它。现在，当我走近变暗的树林时，另一只动物，像天上的云一样白，从它的黑色双胞胎身后走了出来。尽管它们的轮廓笔直平坦，但我还是能看到羊毛外套的最细微细节。

「你们是羊，」我笑着说，伸手去摸其中一只。我没过脑子。我不是故意要打它的。

那只动物尖叫一声，闪烁着粉红色的红光，跑进了树林。「哦，对不起！」我在后面喊道。「对不起，小羊！」我感到非常糟糕，转身对它那无动于衷的朋友语无伦次地说，「我真的不是故意的。我还是不知道怎么使用这个身体，你知道吗？」

「咯咯咯，」我的左边传来一个回答。两只小鸟，每只大约一个方块高，正在啄食附近的地面。它们有短而细的腿，覆盖着白色羽毛的丰满身体，以及末端是扁平橙色喙的小脑袋。

「我不确定你们是不是鸡，」我告诉它们。「你们确实有点像鸭子的特征。」它们抬头看了我一秒钟，咯咯叫着。「但你们听起来像鸡，」我继续说，「所以我猜叫你们鸡比叫……鸡鸭更有道理。」

这个词让我轻笑了一声，很快变成了真正的捧腹大笑。笑的感觉真好，释放了一整天疯狂的紧张感。

就在这时，我听到了一个新的声音。

「呃呃呃。」

那是一种喉咙里发出的、带痰的咕噜声，让我脊背发凉。我环顾四周，试图找出源头。在这个岛上，声音似乎来自四面八方。我站在那里听着，希望那些鸡能闭嘴。

然后我闻到了它。霉味和腐烂味。就像旧袜子里的一只死老鼠。直到它离我只有十几步远的时候，我才看到那个身影。起初我以为是另一个人，穿着和我一样，我不由自主地向前迈了一步。

然后，同样出于本能，我停下来并后退。它的衣服破烂不堪，肮脏污秽。它的肉是斑驳的绿色。它的眼睛，如果你可以称之为眼睛的话，只不过是扁平、静止的脸上毫无生气的黑点。记忆涌入我的脑海，那些我从故事中知道但从未亲眼见过的生物的图像。现在它就在这里，伸着双臂向我走来。

这是一个僵尸！

我试图撤退，撞到了一棵树上。僵尸逼近了。我躲闪。腐烂的拳头砸在我的胸口，把我击退。疼痛传遍全身。我喘着粗气。它猛扑过来。我逃跑了。

恐惧让我麻木，我向山上冲去。我没有思考，没有计划。恐惧驱使着我的每一步。身后黑暗中传来「咔哒」一声，紧接着是像鞭打空气一样的声音。有什么东西撞到了我面前的树上。一根羽毛尖端、颤抖的棍子。一支 _箭_！僵尸有武器吗？我没注意。我只是不停地跑。

右边有什么红色的东西闪过：一簇眼睛，紧接着是一声短促的嘶嘶声。我爬上山坡，直到到达山顶才回头看了一眼。在升起的方形月亮的苍白光芒下，我可以看到僵尸还在追来。它已经到了坡底，开始爬上来追我。

恐惧让我喉咙发紧，我顺着东边的悬崖冲了下去。我滑倒了，摔到了底部，听到了一声令人作呕的断裂声。

「嘶，」当剧痛刺穿我的脚踝时，我倒吸一口凉气。

去哪里？做什么？我应该跳回海里试着游走吗？我在漆黑的水边僵住了。如果那只鱿鱼还在外面，如果它饿了怎么办？

另一声呻吟在星夜中回荡。我转身看到僵尸的头从山顶探了出来。

我疯狂地寻找去处。某个藏身之处。

我的眼睛来回扫视，落在我早些时候挖出的那一块泥土上。从中迸发出了一个绝望的想法。挖掘！

当僵尸开始下坡时，我跑到它下面的悬崖边，疯狂地撕扯着泥土。一二三四拳，我面前的第一块方块掉了下来。一二三四，后面的一块也弹了出来。

我能听到食尸鬼逼近的声音，每一声呻吟都越来越大。一二三四，一二三四。我在正前方清理了四个泥土方块，上下各两个。刚好够我挤进那个空间。

*更深，*我的大脑尖叫着。_挖得更深！_

如果命运会说话，它会冷笑着说：「你哪儿也去不了。」

我的拳头弹回了某种冰冷坚硬的东西。我撞到了坚硬的岩石。几下毫无意义的拳击告诉我，我被困住了，怪物就在几秒钟之外。

我转身，看到了僵尸，并在我们之间放置了一块泥土。食尸鬼伸出手，砸在我的胸口。我向后飞去，撞到了石崖上。胸口疼痛，大口喘着气，我把第二块泥土方块塞在第一块上面。

黑暗降临。我被活埋了。

我的坟墓隔绝了光线，但没有隔绝声音。僵尸的呻吟声仍然在我耳边回响。如果它能挖掘怎么办？如果我只是把死亡推迟了几秒钟怎么办？

「走开！」我无助地喊道。「求求你别管我！」

令人作呕的咆哮声回答了我。

「求求你！」我恳求道。

无情、冷漠、不可阻挡的呻吟声回答了我。

「醒醒，」我低语道。「我必须醒醒，醒醒，醒醒！」

绝望中，我开始上下跳跃，头撞着天花板，试图把自己震醒。

「醒醒醒醒醒醒！」

我倒在石墙上，头痛欲裂，眼睛灼烧，胸口因急促、恐慌的抽泣而起伏。

「为什么？」我呜咽着。「为什么我醒不过来？」

就在这时，僵尸发出了一声低沉、猛烈的呻吟。_「因为它不是梦。」_

不，那个生物并没有对我说话。我把话塞进了它腐烂的嘴里，那些我知道我需要听到的话。

*「这不是梦，」*我想象着听到那具移动的尸体说，_「这也不是受伤或幻觉。这是一个真实的地方，一个真实的世界，你必须接受这一点才能生存。」_

「你是对的，」我对食尸鬼说，知道我是在自言自语，但仍然觉得和一个死人说话在某种程度上更理智。「这并没有发生在我的脑海里。这正在发生。」

一首半记得的歌曲的片段飘过我失忆的迷雾。关于发现自己在一个陌生的地方。我记不清所有的歌词，但有一句清晰地印在我的脑海里：

_你可能会问自己，好吧，我是怎么到这里的？_

「我不知道，」我承认。「我不知道我是怎么到这里的，甚至不知道『这里』是哪里。另一个星球？另一个维度？我不知道，但我知道再否认也没有意义了。」

随着这种接受，一股巨大的平静涌上心头，随着平静而来的是一个新的口头禅。

「恐慌淹没理智，」我告诉僵尸，「所以是时候停止恐慌，开始弄清楚如何生存了。」
